## 🔧 **TROUBLESHOOTING:**

### **Проблема:** "MetaTrader5 not found"
**Решение:** Это нормально для Linux/Mac. MT5 работает через Flask API.

### **Проблема:** "GPTService missing api_key"
**Решение:** Настройте API ключи в `configs/` или используйте демо-режим.

### **Проблема:** "No module named 'flet'"
**Решение:** 
```bash
pip install flet plotly pandas numpy MetaTrader5
```

### **Проблема:** "Connection to Flask API failed"
**Решение:** Запустите MT5 сервер на Windows или используйте демо-данные.
