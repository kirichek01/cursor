# 🖥️ ТОРГОВАЯ СИСТЕМА v2.0 - ЛОКАЛЬНОЕ РАЗВЕРТЫВАНИЕ НА WINDOWS

## ✅ **ВЫ АБСОЛЮТНО ПРАВЫ!**

**Web-версия НЕ подходит** для полного функционала. Нужен **локальный запуск на Windows** с виртуальным окружением для работы с MT5 и Telegram сессиями.

---

## 🎯 **ПОЧЕМУ ЛОКАЛЬНО НА WINDOWS:**

### **❌ Ограничения web-версии:**
- ❌ Невозможно создать Telegram сессии (блокировка браузера)
- ❌ Нет прямого доступа к MT5 (только через API)
- ❌ Ограниченный доступ к файловой системе
- ❌ Проблемы с SMS кодами и авторизацией

### **✅ Преимущества локального запуска:**
- ✅ **Полная работа с Telegram** (создание сессий, SMS коды)
- ✅ **Прямое подключение к MT5** (без промежуточных API)
- ✅ **Полный доступ к файлам** и системным ресурсам
- ✅ **Максимальная производительность**
- ✅ **Полная безопасность** (все локально)

## 🔧 **TROUBLESHOOTING:**

### **Проблема: "Python не найден"**
**Решение:** Скачайте Python 3.8+ с python.org

### **Проблема: "MT5 не подключается"**
**Решение:** 
1. Установите MetaTrader 5
2. Запустите MT5 и подключитесь к брокеру
3. Перезапустите торговую систему

### **Проблема: "Telegram код не приходит"**
**Решение:**
1. Проверьте номер телефона
2. Попробуйте получить код через Telegram app
3. Убедитесь что API данные верные

### **Проблема: "Виртуальное окружение не активируется"**
**Решение:**
```bash
# Создайте заново:
rmdir /s trading_venv
python -m venv trading_venv
call trading_venv\Scripts\activate
pip install -r requirements.txt
```
