## 🔧 Технические улучшения

### API Endpoints в расширенном сервере
```
GET  /health        - Расширенная информация о состоянии
POST /initialize    - Инициализация с сохранением конфигурации  
GET  /account_info  - Информация о реальном торговом счете
GET  /positions     - Открытые позиции с временными метками
GET  /rates         - Котировки с расширенными параметрами
GET  /config        - Текущая конфигурация (без паролей)
POST /shutdown      - Корректное закрытие соединения
```

### Безопасность
- 🔒 Пароли не сохраняются в конфигурационных файлах
- 🔒 Безопасная передача чувствительных данных через API
- 🔒 Валидация состояния подключения
- 🔒 Детальное логирование для аудита

### Надежность
- 🛡️ Проверка состояния подключения к MT5
- 🛡️ Обработка потери соединения
- 🛡️ Автоматическое восстановление конфигурации
- 🛡️ Детальные сообщения об ошибках

## 🌐 Настройка для виртуальной машины

### Конфигурация сети
```bash
# VirtualBox: Настройки VM → Сеть → Сетевой мост
# VMware: VM Settings → Network → Bridged

# Брандмауэр Windows
netsh advfirewall firewall add rule name="MT5 Server" dir=in action=allow protocol=TCP localport=5000

# Получение IP-адреса
ipconfig  # Например: 192.168.1.100

# Доступ к серверу
http://192.168.1.100:5000
```

## 🚀 Запуск системы

### 1. Очистка базы данных (опционально)
```bash
# Для создания чистой базы без старых демо-данных
rm trading_data.db
```

### 2. Запуск MT5 сервера на Windows
```bash
# Запуск расширенного сервера (рекомендуется)
start_mt5_server_enhanced.bat

# Или обычного сервера
start_mt5_server.bat
```

### 3. Настройка конфигурации
```bash
# Скопировать и настроить конфигурацию
copy mt5_config.example.json mt5_config.json
# Отредактировать mt5_config.json с реальными данными
```

### 4. Инициализация MT5
```bash
# Через API
curl -X POST http://localhost:5000/initialize -H "Content-Type: application/json" -d '{"path":"C:\\Program Files\\MetaTrader 5\\terminal64.exe","login":ВАША_УЧЕТНАЯ_ЗАПИСЬ,"password":"ВАШ_ПАРОЛЬ","server":"ИМЯ_СЕРВЕРА"}'
```

### 5. Запуск основного приложения
```bash
python main.py
```
